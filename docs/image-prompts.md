# Copy-paste prompts for ChatGPT

Nineteen self-contained prompts. Nothing to assemble — paste one, save the
result with the filename in its heading into `public/images/rv-images/`, tell me
when they're in, and I wire them to the slots.

**Do this first:** attach your reference photos to the chat and say *"Match the
vehicle in these photos in every image I ask for."* Then keep working in that
same chat so ChatGPT holds the design in context. Re-attach the references every
few prompts if it starts drifting.

**If a result comes back wrong**, reply in the same chat rather than restarting:

- Vehicle has a cab → *"That's a motorhome. This is a TOWED trailer — remove the cab, windshield, wipers and front wheels. Front should be a blank faceted nose with an A-frame hitch."*
- Roof isn't raised → *"The expansion is vertical: the entire roof lifts straight up, revealing a continuous band of glass all the way around beneath it."*
- Looks like CGI → *"Too CGI. Make it a real photograph — natural light falloff, real atmosphere, slight sensor grain, imperfect surfaces."*
- Invented lettering → *"Remove all text and badges from the vehicle."*

Export **JPEG, quality 80**, 2400px long edge (hero 3000px). Portrait variants
1600px wide.
