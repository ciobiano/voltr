Foundries, typefaces, hierarchy systems, and the recommended VOLTR type system. Swiss + architectural direction.

Primary Foundries

Grilli Type

grillitype.com — Swiss type foundry, designed the custom Lucid font

Key faces for VOLTR

  • GT America — "Bridge between American Gothics and European Neo-Grotesk." 84 styles. Versatile, clean, authoritative. UI body + headlines.
  • GT Pressura — "Inspired by engineered letters stamped on shipping boxes." Squared, industrial, compressed. Ink-trap detailing. 36 styles. Ideal for data-heavy UI and metrics. Monospaced version available.
  • GT Flexa — Wide, display-oriented. For cinematic headline moments.
  • GT Planar — Constructed, geometric, almost architectural.
  • GT Cinetype — Designed for cinema/automotive contexts. Technical, precise.

Why they fit

Grilli Type designed the Lucid custom font. Their catalog covers the full spectrum: UI text (GT America) → display headlines (GT Flexa) → data/metrics (GT Pressura Mono). Swiss precision without coldness.

Lineto

lineto.com

  • LL Unica77 — What Polestar uses. Category-neutral, timeless. "Neither geometric nor grotesque but sits in between." Clean, pure, technically precise.
  • LL Supreme — "Futura as it should have been." Rebuilt geometrically from scratch. Display version for dramatic headlines.

Swiss Typefaces

swisstypefaces.com

  • Suisse Int'l — Neo-grotesque flagship. Maximum Swiss restraint and architectural precision. Wide weight range.
  • Suisse Screen — Optimized for digital: large apertures, open counters, barred I. Engineered for on-screen legibility.
  • Simplon — Industrial sans, monolinear. Inspired by European road signage. Technical flavor, "engineer-like monolinearity." Has Mono companion.
  • Only Extended — Extended-by-design. Monospace-inspired letter shapes. Ultra-modern geometry + Swiss grotesque. Short ascenders/descenders for compact density.

Dinamo

abcdinamo.com

  • ABC Gravity — 12 widths (XXXX Compressed to Wide), variable font. Extreme headline width control.
  • ABC Ikarus — Neue grotesk for layouts.
  • ABC Publisher — Text-optimized for long-form reading.

Automotive-Specific Typography

Monotype Automotive Collection

  • Burlingame — Designed specifically for automotive displays. Flat terminals, sharp corners, super-elliptical bowls, generous spacing. Tested via Monotype's automotive UI legibility research.
  • Daytona — Sturdy, squared letters, narrow for space efficiency. Rounded corners, open counters.
  • Trade Gothic Next — "Most legible of the Grotesque Sans genre."

Volvo Centum (Dalton Maag)

Custom typeface engineered for "extreme legibility" at a glance. Open counters, character disambiguation (every letter clearly distinguishable). Boxy curves, clean horizontal terminals. Designed for quick comprehension in bright daylight or low-light conditions. References 1990s Volvo 850 tail lamps — heritage cues through typography.

Pattern: Brand heritage can live in letterforms. Terminal treatments and curve shapes can reference physical design cues.

Architectural / Precision Typefaces

  • Cine Type Fabbrica — "Letters are like concrete blocks." Homogeneous widths, closed shapes, technical engineered nature, softened by rounded corners. "Constrained dynamism."
  • Zosma — "Engineered rather than drawn." Angled cuts, squared counters, taut curves.
  • Noe Display (Schick Toikka) — High-contrast serif for dramatic headline moments. Use extremely sparingly.

Recommended VOLTR Type System

Primary: GT America

Usage: UI, body, navigation. 84 styles cover all UI needs. Bridge between American Gothic and Neo-Grotesk. Clean but not cold.

  • Sizes: 14-16px body, 24px+ UI labels
  • Weights: Regular for body, Medium for emphasis. No Bold in UI.

Display/Headline: LL Supreme Display or GT Flexa

Usage: Cinematic headline moments. Display sizes only (48px+).

  • Tracking: +50 to +150 for cinematic feel
  • Weights: Light or Regular for calm. Medium for authority.

Data/Metrics: GT Pressura Mono or Simplon Mono

Usage: Data readouts, specifications, metrics panels.

  • Sizes: 14-20px for data readouts
  • Tabular lining figures ON by default

Usage Rules

  • No more than 2 families in a single view (one proportional + one mono)
  • One weight per size — Polestar's approach
  • Minimum 24dp for body/interactive text (AAOS mandate)
  • 4dp grid for all typographic alignment
  • Avoid bold — use Medium at most (bold reduces glance legibility)
  • Wide tracking only for display/hero — never for body or data

Palette Alignment

  • Dark background: #0A0A0A or similar deep neutral
  • Primary text: #E8E8E8
  • Secondary text: #888888
  • Accent: warm metal (gold #C9A96E or copper #B87333) or cool (ice blue #4A8FE7)
  • Status colors reserved for safety-critical only (aviation "quiet, dark" philosophy)

What to Avoid

Pitfall Why
Gamified/gradient gauges Distracts, dates fast, contradicts "calm"
Multiple typefaces per view Clutters. Polestar uses one face everywhere.
Bold weights in UI Slower glance recognition per AAOS research
Always-on data Show only when relevant
Purple/neon gradients Generic AI aesthetic, not engineering precision
Thin stroke on dark Legibility failure in low light / glare
Ornamental serifs Too much personality; undermines "engineering"
Stretched/condensed body text Display sizes only

System Extraction — Typography Principles

Principle Rule
Two-family maximum One proportional + one mono per view
One weight per size No mixing Light/Regular/Bold at the same size
No UI bold Medium is the maximum for body/interactive
Cinematic tracking +50 to +150 letter-spacing for display only
Tabular figures All data uses tabular lining, not proportional
Generous leading 25-33% of font size (aviation standard)
Min 24dp interactive All touch/click targets minimum 24dp
